# Проверка проекта на 29 сентября 2026 года

## Результаты

- Локальный запуск `.venv/bin/python -m pytest -q`: 20 тестов прошли. Есть два предупреждения совместимости FastAPI и Starlette с тестовым HTTP-клиентом.
- Серверный контейнер `maxbot-app-1` работает и имеет статус `healthy`. Сборка Docker-образа из `/opt/maxbot` завершилась успешно без остановки приложения. Контрольные суммы `Dockerfile`, зависимостей и ключевых файлов приложения на VPS совпали с исходниками Git.
- Публичный HTTPS-сервис вернул HTTP 200 для `/`, `/health`, `/docs`, `/openapi.json` и `/static/app.js`. Запрос к `/api/me` без сессии вернул HTTP 401. OpenAPI содержит 32 маршрута, включая вход, регистрацию, дневник и уроки.
- MAX API подтвердил бота `t696_hakaton_max_bot` и одну подписку на действующий webhook. Пользователь открыл мини-приложение в мобильном MAX и прислал снимок рабочего главного экрана с профилем ученика 7 класса. Веб-клиент MAX и полный урок в реальном интерфейсе этим снимком не проверены.
- Сквозной тест API в работающем контейнере прошёл на отдельной временной SQLite-базе: подпись MAX WebAppData, вход, регистрация, профиль, синтетический дневник, ограничение предметов по классу, создание задания на урок, получение пяти шагов от RouterAI, упрощение объяснения, проверка неверного и верного ответа, запрет пропуска шага, сохранение прогресса и генерация теста из пяти вопросов. Данные действующих учеников тест не затронул.
- Презентация для сдачи содержит 20 непустых слайдов в PPTX и PDF. На первом слайде есть бот, репозиторий, ссылка на коммит, собственный API, AI-ключ и сценарий проверки. В PDF работают пять внешних ссылок. Опрос 49 учеников 1–7 классов описан как исследование проблемы; измеренного эффекта продукта презентация не заявляет.
- Проверены все достижимые коммиты Git: заполненный `.env` и ключ AI в истории репозитория не обнаружены. Токен AI хранится на VPS и на служебном слайде по разрешению команды. Заполненный `.env` в архив и Git не включён.

## Границы проверки

- Локальный Docker daemon на Mac не запущен, поэтому локальную сборку заменили сборкой на VPS из того же проверенного кода.
- Из этого окружения нельзя автоматически пройти урок в мобильном или веб-клиенте MAX. Снимок пользователя подтверждает открытие главного экрана в мобильном клиенте, а сценарий обучения проверен через тот же серверный код и реальный RouterAI в отдельной тестовой базе.
- Дневник синтетический; настоящей интеграции со школьной системой нет. Данные опроса получены от команды, исходные анкеты не представлены.
